Also refer to README.md for tutorial.

The project was developed using uv, therefore the easiest way to run the project is to install uv first:

curl -LsSf https://astral.sh/uv/install.sh | sh

With it installed, just run:
uv sync
uv run src/main.py

To run our SparQL queries run:
uv run src/sparql.py

Main file parses the XML files and adds entities to the correct Classes, completing with the correct information
